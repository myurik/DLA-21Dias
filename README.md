# 🧠 Desafio Lógica Afiada — 21 Dias

Repositório com a resolução dos desafios do **Desafio Lógica Afiada em 21 dias**, criado pelo canal [Código Fonte TV](https://www.youtube.com/@codigofontetv) (Gabriel Fróes e Vanessa Weber).

> 💡 O desafio propõe exercícios diários de raciocínio lógico, evoluindo aos poucos para desafios de lógica de programação em **JavaScript**.

🔗 Site oficial do desafio: [desafiologicaafiada.com.br](https://desafiologicaafiada.com.br)

---

## 📌 Sobre o desafio

- Duração: 21 dias corridos, com desafio(s) novo(s) a cada dia
- Os primeiros dias focam em lógica "no papel" (sem código), como forma de treinar abstração e pensamento algorítmico antes de partir para a programação
- Conforme os dias avançam, os desafios passam a envolver código em JavaScript

## 🛠️ Como eu resolvo os desafios

Quando o desafio envolve código, o fluxo que uso é:

1. Resolvo e testo o desafio localmente no **VS Code**
2. Copio o código final para o **[PlayCode.io](https://playcode.io/)**, gerando um link compartilhável
3. Envio o link do PlayCode na plataforma do curso e registro esse link aqui no repositório (na tabela de progresso abaixo e/ou no `anotacoesX.md` do dia)

Quando o desafio é só de lógica/raciocínio (resolvido em papel, sem código — como o Dia 1), guardo apenas minhas anotações sobre o processo de pensamento.
